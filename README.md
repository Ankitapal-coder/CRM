# CRM - Customer Relationship Management System

A full-stack CRM application designed to manage customers, leads, authentication, and sales activities efficiently.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Role-based access
- Lead Management
- Lead Status Tracking
- Search & Filter Leads
- Dashboard Statistics
- Delete Leads
- REST API Integration

## 🛠️ Technologies Used

### Frontend
- React.js
- JavaScript
- CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
